# Data

This repo expects `car_data.csv` in this folder. The file is a third-party public dataset and is not redistributed here.

Download it from the public CarDekho "Vehicle dataset" (columns Car_Name, Year, Selling_Price, Present_Price, Kms_Driven, Fuel_Type, Seller_Type, Transmission, Owner) on Kaggle: https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho

and save it as `data/car_data.csv`, then run the script from the repository root.
